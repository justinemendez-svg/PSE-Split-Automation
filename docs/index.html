Using the dashboard

The list shows closed Opportunities with a Partner tagged where the PSE still needs to be added to the Opportunity Team, Opportunity Splits, or both. When the PSE field is blank, these checks use the tagged Partner’s Owner.

Upload the data

First time downloading the data? . The guide includes a prompt for your Codex and the manual upload steps. Closing the guide takes you to Upload the data.

Run the local Salesforce export command, then click Upload the data and choose the generated pse-data.json. Uploading replaces the shared saved snapshot. Opening or reloading this dashboard shows the last uploaded file; Google Drive changes are not imported automatically.

Use the local dashboard for Salesforce updates. The hosted dashboard supports the worklist, filters, and CSV export.

Refresh

Click Refresh to pull the latest data from Salesforce. The dashboard updates its counts and list based on the current Opportunity, Partner, PSE, Team, and Split records in SFDC. Data refreshes only when this button is clicked. Opening or reloading the page shows the last saved data.

Clickable boxes

Click a box to filter the list by category:

  1. Opps with tagged correct PSE: Closed Opportunities with a Partner where the tagged PSE and Partner Account Owner are the same user, and that PSE is missing from the Opportunity Team, Opportunity Splits, or both.
  2. Opps with Partner, PSE different from Owner: Closed Opportunities with a Partner where the tagged PSE and Partner Account Owner are different users, and that PSE is missing from the Opportunity Team, Opportunity Splits, or both. Update preserves the existing tagged PSE.
  3. Partner but no tagged PSE: Closed Opportunities with a Partner but a blank PSE field, where the Partner’s Owner is missing from the Opportunity Team, Opportunity Splits, or both. The Owner is the PSE that will be used when you click Update.
  4. All Opps to update: Closed Opportunities with a Partner, with or without a tagged PSE, that still need a Team or Split update.

What “missing” means: If the rep is already on the Team but has no Split, the Opportunity stays in the list. The same applies if the rep has a Split but is missing from the Team. If the rep is already on both, the Opportunity is excluded from all three boxes.

Search and filters

Search by Opportunity name, Opportunity ID, or Account name. Use the filters below to narrow the selected category. You can select multiple values in each filter; selections across different filters work together. Clear a filter’s selections to remove that restriction.

Fiscal Quarter–Year
Filters by Opportunity Close Date using Zendesk’s fiscal calendar: Q1 Feb–Apr, Q2 May–Jul, Q3 Aug–Oct, and Q4 Nov–Jan. For example, November 2026 through January 2027 is FY2027 Q4.
Opportunity Type
Choose Renewal, New Business, Expansion, or a combination.
Market Segment
Filters by the Opportunity’s Account Owner Market Segment.
Region
Filters by the Region recorded on the Opportunity.
PSE Status
Choose Active, Inactive, or both. If a PSE is tagged, this is that user’s status. If the PSE field is blank, this is the Partner Owner’s status.

The box counts reflect your search and filters. The matching-PSE, different-PSE, and no-PSE categories are separate. User IDs determine whether the PSE matches the Partner Account Owner; older exports use names until fresh data is exported. Records without enough information to compare stay visible in All Opps to update.

Update and export

Update in Salesforce applies the process to one Opportunity after confirmation. Update all N in Salesforce applies it to all matching results across all pages, using your selected box, search, and filters. Export CSV downloads that same filtered list.

Refresh only reads Salesforce. Update actions preserve an existing PSE, populate a blank PSE from the tagged Partner’s Owner, and add missing Team and Split entries. Each Opportunity uses its own PSE. Existing entries are preserved; Salesforce errors are reported so you can retry the remaining steps.

Scope: Commissionable Renewal, New Business, and Expansion Opportunities at Stage exactly 08 - Closed, with a Partner tagged. Partners with Partner Type Startup Program Partner are excluded.

First-time setup instructions

Set up your Salesforce download once, then upload fresh data manually

Before you start

You need your own Salesforce account with API access and permission to read the required records, Google Drive for desktop with GTM Ops/MSS/PSE_Split_Automation synced and writable, and Codex running on your computer. The repository is public: PSE-Split-Automation on GitHub.

1 · Paste this prompt into your Codex

To set up the download to Google Drive, copy the complete prompt below, paste it into a new Codex chat on your computer, and send it. Follow any installation or Salesforce/Okta sign-in steps Codex shows you. Each person must use their own account and local folder path.

2 · Check the downloaded file

Wait for Codex to confirm the export succeeded. It should report the extraction date, Opportunity count, and full path to pse-data.json in your synced PSE_Split_Automation folder. Wait for Google Drive to finish syncing. Keep the exact reusable export command Codex gives you.

3 · Upload the file manually

  1. Click Close · Back to Upload at the top of this guide. You will return to Upload the data.
  2. Choose pse-data.json from your synced GTM Ops/MSS/PSE_Split_Automation folder. Use JSON, not the dashboard’s Export CSV file. Maximum size: 25 MB.
  3. Check the extraction date and record count shown in the preview, then click Upload data to dashboard.
  4. Wait for Upload complete, then click Close · Back to dashboard to view the updated counts and list.

Next time you need fresh data

Return to Upload the data, copy the refresh command into your Codex chat, and wait for the export and Google Drive sync to finish. Then repeat the manual upload steps above. First-time setup is only needed again if your computer, Salesforce access, or Drive folder changes.

What changes: the command reads Salesforce and replaces the shared Google Drive export. Uploading replaces the saved data for everyone using this dashboard. Neither step updates Salesforce records. There are no scheduled downloads or automatic uploads.

Pressing Escape also closes this guide and returns you to the Upload page.
