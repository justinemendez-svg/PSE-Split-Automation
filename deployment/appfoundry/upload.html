PSE Split Automation

First-time setup instructions

Set up your Salesforce download once, then upload fresh data manually

Before you start

You need your own Salesforce account with API access and permission to read the required records, Google Drive for desktop with GTM Ops/MSS/PSE_Split_Automation synced and writable, and Codex running on your computer. The repository is public: PSE-Split-Automation on GitHub.

1 · Paste this prompt into your Codex

To set up the download to Google Drive, copy the complete prompt below, paste it into a new Codex chat on your computer, and send it. Follow any installation or Salesforce/Okta sign-in steps Codex shows you. Each person must use their own account and local folder path.

2 · Check the downloaded file

Wait for Codex to confirm the export succeeded. It should report the extraction date, Opportunity count, and full path to pse-data.json in your synced PSE_Split_Automation folder. Wait for Google Drive to finish syncing. Keep the exact reusable export command Codex gives you.

3 · Upload the file manually

  1. Click Close · Back to Upload at the top of this guide. You will return to Upload the data.
  2. Choose pse-data.json from your synced GTM Ops/MSS/PSE_Split_Automation folder. Use JSON, not the dashboard’s Export CSV file. Maximum size: 25 MB.
  3. Check the extraction date and record count shown in the preview, then click Upload data to dashboard.
  4. Wait for Upload complete, then click Close · Back to dashboard to view the updated counts and list.

Next time you need fresh data

Return to Upload the data, copy the refresh command into your Codex chat, and wait for the export and Google Drive sync to finish. Then repeat the manual upload steps above. First-time setup is only needed again if your computer, Salesforce access, or Drive folder changes.

What changes: the command reads Salesforce and replaces the shared Google Drive export. Uploading replaces the saved data for everyone using this dashboard. Neither step updates Salesforce records. There are no scheduled downloads or automatic uploads.

Pressing Escape also closes this guide and returns you to the Upload page.
